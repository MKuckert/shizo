Control what your AI agent can run.

Fail-closed Bash allowlisting for Claude Code.

bash-gate is a PreToolUse hook that parses shell syntax, resolves executables, and matches commands against a line-oriented rule set. Anything it cannot statically verify is denied.

How it works

1

Parse

Full shell syntax parse — pipes, chains, subshells, redirections.

2

Resolve

Every command is resolved against PATH and a trusted-directory set.

3

Sandbox check

Verify the sandbox capability file is present; deny everything otherwise.

4

Match rules

Argv tokens matched against allow/deny rules with ANY and HAS wildcards.

5

Decide

A deny always wins. Unmatched commands fall through to ask.

Rules at a glance

# Directives (global tier only)
sandbox nono
trust   /usr/bin
trust   /opt/homebrew/bin

# Allow safe reads
allow git status ANY
allow git log ANY
allow git diff ANY

# Block destructive operations
deny git push ANY
deny git reset HAS --hard
